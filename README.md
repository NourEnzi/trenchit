# Trench-It CLI 🚀

Terminal-style commands to force deep technical responses and eliminate AI model laziness (truncation, fluff, and generic answers) across platforms like ChatGPT, Claude, and Gemini.

## 🛠️ Features
- **`/trench.code`**: Forces complete, production-ready code with zero placeholders (`// rest of code here`).
- **`/trench.raw`**: Drops all conversational filler, apologies, and generic introductions.
- **`/trench.arch`**: Engages Senior Systems Engineer mode, focusing on edge cases, data structures, and markdown tables.
- **`/trench.biz`**: Delivers strict actionable items and KPIs in structured bullet points.

## 📥 Installation Guide (Manual / Developer Mode)

Since this extension is open-source and lightweight, you can install it locally in less than 30 seconds:

1. **Download:** Click [here to download the repository as a ZIP file](../../archive/refs/heads/trenchit-main.zip) (or clone the repo) and extract the files into a folder on your computer.
2. **Open Extensions Page:** 
   - In Google Chrome, type `chrome://extensions/` in the address bar.
   - In Microsoft Edge, type `edge://extensions/`.
3. **Enable Developer Mode:** Toggle the **Developer mode** switch in the top-right corner of the page.
4. **Load the Extension:** Click the **Load unpacked** button in the top-left and select the folder where you extracted the files.
5. **Ready to Use:** Open ChatGPT, Claude, or Gemini, type any of the commands (e.g., `/trench.code`) followed by a space, and watch the prompt transform instantly!
